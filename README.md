# kikimimi (聞き耳)

Google Cloud Text-to-Speech (Chirp3-HD) を使用した、Discord向けの高品質な読み上げボイスボットです。

## 主な機能
- 高品質読み上げ: Googleの最新モデルによる自然な日本語音声。
- 自動接続/切断: VCへの入退室を検知して自動で読み上げを開始・終了します。
- ボイス選択: ユーザーごとに25種類のボイスから好きな声を選べます。
